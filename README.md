# Mahjong Score Table

A one-page score keeper for mahjong with friends: https://shiyuandeng.github.io/mahjong/

- Any number of players; pick who sits East, South, West and North each game
- Tap the winner, tick each 牌型, and the fan and payments are worked out
- Rules page with an explanation and example tiles for every 牌型
- Leaderboard, settle up, and optional pence per point
- Hong Kong rules for now. Rule sets live in the `RULESETS` object in `index.html`

Scores are kept in the browser of the phone that records them.
